# Enkelt Sudoku-spill (terminal)

Dette prosjektet inneholder et enkelt Sudoku-spill i Python som kjører i terminalen.

## Kjør spillet

```bash
python3 sudoku.py
```

## Kommandoer i spillet

- `sett R C N` – sett tall `N` i rad `R`, kolonne `C`
  - Rad og kolonne: `1-9`
  - Tall: `1-9`
  - Bruk `0` for å tømme en rute
- `vis` – viser brettet
- `hjelp` – viser hjelp
- `slutt` – avslutter spillet

## Eksempel

```text
> sett 1 3 4
Trekk registrert.
```
